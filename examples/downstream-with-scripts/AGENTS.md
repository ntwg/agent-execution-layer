This repo uses the Agent Execution Layer (`ael`) as its workflow authority.

## Start Here

Before taking any action, run:

```bash
npm run ael:status
```

Then read:

- `.ael/agent-guide.md`

If config is missing, run:

```bash
npm run ael:init
npm run ael:doctor
```
